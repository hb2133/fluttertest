# FLUTTER PLATFORM PROFILE (DESKTOP) V2

## 1) 문서 역할
- 이 문서는 Flutter 데스크톱(Windows/macOS/Linux) UI/UX 운영 규칙이다.
- 구조와 계층의 기본 규칙은 `ARCHITECTURE_RULES_PANEL_SECTION_FLUTTER_V1.md`, `ARCHITECTURE_RULES_PANEL_LAYER_FLUTTER_V1.md`를 따른다.
- 본 문서는 데스크톱 presentation 품질 기준만 추가로 고정한다.

## 2) 기본 입장
- 데스크톱 기본 레이아웃은 `split-pane` 또는 `multi-pane`다.
- 창 크기 변경과 최소 창 크기 정책을 명시적으로 처리한다.
- 마우스, 키보드, 우클릭, 단축키를 1급 입력으로 다룬다.
- 높은 정보 밀도를 허용하되 가독성과 포커스 이동을 해치지 않는다.

## 3) 크기 클래스
- `compact`: 0 ~ 1023dp
- `expanded`: 1024 ~ 1439dp
- `wide`: 1440dp 이상
- 권장 최소 창 크기: 960x640

## 4) 레이아웃 규칙
- `expanded` 이상에서는 `navigation + content` 분할을 기본으로 한다.
- 좌측 탐색, 중앙 작업, 우측 상태/속성의 책임을 분리한다.
- 패널 접기/펼치기 상태는 `BasePanel Controller`에서 관리한다.
- 리사이즈 시 즉시 재배치되어야 하며 고정 픽셀 폭 남용을 금지한다.
- `compact`에서는 일부 패널을 drawer 또는 overlay로 대체할 수 있다.

## 5) 입력 / 상호작용 규칙
- hover, 포인터 커서, 포커스 표시를 의미 있게 제공한다.
- 핵심 액션은 단축키를 지원한다.
- 키보드만으로 주요 흐름 수행이 가능해야 한다.
- 우클릭 컨텍스트 메뉴를 지원하되 모바일 전용 플로우에 의존하지 않는다.

## 6) 스타일 / 정보 밀도 규칙
- 색상, 간격, 타이포, 반경, 그림자는 `lib/design/global_design.dart` 토큰만 사용한다.
- 클릭 타깃은 과도하게 줄이지 않는다.
- 데이터 테이블과 리스트는 정렬, 선택, 빈 상태를 명확히 보여준다.
- 다중 패널에서도 Primary/Secondary 시각 우선순위를 유지한다.

## 7) 성능 / 안정성 규칙
- 대량 목록과 트리는 지연 렌더링 또는 가상화를 우선 검토한다.
- 파일 I/O, 검색, 파싱 등은 UI 스레드를 장시간 점유하지 않게 처리한다.
- 장기 작업은 진행 상태와 취소 또는 재시도 경로를 제공한다.
- 실패 상태는 가능한 패널 단위로 격리한다.

## 8) 접근성 규칙
- 텍스트 대비와 폰트 가독성을 유지한다.
- 아이콘 단독 버튼에는 레이블 또는 툴팁을 제공한다.
- 키보드 포커스 순서는 읽기 흐름과 일치해야 한다.
- 상태 변화는 색상 외 텍스트나 아이콘으로도 전달한다.

## 9) 데스크톱 스모크 체크
- 1280x720에서 핵심 흐름이 유지된다.
- 1440x900에서 split-pane 배치가 안정적이다.
- 1920x1080에서 정보 밀도 증가 시 가독성이 유지된다.
- 리사이즈, 단축키, 우클릭, 포커스 이동이 충돌 없이 동작한다.

## 10) 완료 기준
- `dart format --set-exit-if-changed .`
- `flutter analyze`
- `flutter test`
- 데스크톱 스모크 체크 통과
